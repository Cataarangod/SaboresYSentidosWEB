# Sabores y Sentidos – Precompra de Navidad
1. Sube esta carpeta a un repo de GitHub (o usa `vercel` en la terminal).
2. En Vercel: Add New → Project → importa el repo. En "Output Directory" escribe `public`.
3. En Settings → Environment Variables agrega:
   - RESEND_API_KEY  (gratis en resend.com)
   - PEDIDOS_TO      (tu correo donde llegarán los pedidos)
4. En `public/index.html` cambia los datos de la cuenta bancaria y las fechas MIN/MAX.
